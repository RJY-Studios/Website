# RJY Studios website

The public website at https://rjystudios.com, served by GitHub Pages from the `main` branch.

- `index.html`: home page
- `privacy/index.html`: Privacy Policy
- `404.html`: page-not-found page
- `assets/site.css`: shared styles (light and dark)
- `assets/theme.js`: the sun/moon light-dark toggle (follows the device until used; remembered per device)
- `CNAME`: the custom domain for GitHub Pages

Plain HTML and CSS, no build step. Edit a file, commit to `main`, and the site updates within a minute or two.
